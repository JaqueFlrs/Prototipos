Entrar a Claude Code con token

Para quien no tiene cuenta propia y le pasaron un token. Sirve en la terminal. En la app de Claude no sirve — eso se explica al final.

Antes de empezar: ¿cómo empieza tu token?

Fíjate solo en los primeros caracteres. Es opcional: si eliges, el paso 2 esconde el comando que no te toca.

Es una API key. El consumo se le factura a quien la generó, por uso. Vas por la Ruta A en el paso 2.

Es un token OAuth, sacado de una suscripción Pro o Max con claude setup-token. Vas por la Ruta B en el paso 2.

  1. 1

    Abre PowerShell e instala Claude Code

    Tecla Windows, escribe powershell, Enter. Pega esto y espera a que termine:

    Instalador 
    irm https://claude.ai/install.ps1 | iex

    Si ya tenías Claude Code instalado, sáltate este paso.

  2. 2

    Guarda el token

    Este es el paso donde se traba la gente, así que va bien despacio. La idea es armar la línea completa en el Bloc de notas y hasta el final pegarla en PowerShell.

    1. Abre el Bloc de notas: tecla Windows, escribe notepad, Enter. Déjalo abierto.

    2. Copia la línea que te toca según cómo empieza tu token, y pégala en el Bloc de notas con Ctrl + V.

      Si tu token empieza con sk-ant-api03
      Guardar API key 
      setx ANTHROPIC_API_KEY "PEGA_AQUI_EL_TOKEN"
      Si tu token empieza con sk-ant-oat01
      Guardar token OAuth 
      setx CLAUDE_CODE_OAUTH_TOKEN "PEGA_AQUI_EL_TOKEN"

    3. Ve al mensaje o correo donde te mandaron el token. Selecciona el token completo, desde sk-ant hasta el último carácter, y cópialo con Ctrl + C.

    4. Regresa al Bloc de notas. Haz doble clic encima de PEGA_AQUI_EL_TOKEN: se pinta toda de azul.

    5. Sin quitar la selección, pega con Ctrl + V. El token entra en el lugar exacto donde estaba esa palabra.

    6. Revisa la línea: debe seguir siendo una sola, con una comilla antes del token y otra después. Si el token quedó cortado en dos renglones, bórralo y vuelve al inciso c.

    7. Selecciona toda la línea con Ctrl + A y cópiala con Ctrl + C.

    8. Ve a la ventana de PowerShell, pega con clic derecho y presiona Enter.

    Cómo debe quedar · sk-ant-api03
    Así NO — sin reemplazar setx ANTHROPIC_API_KEY "PEGA_AQUI_EL_TOKEN"
    Así SÍ — token real adentro setx ANTHROPIC_API_KEY "sk-ant-api03-Ab3xK9...z7Qw"
    Cómo debe quedar · sk-ant-oat01
    Así NO — sin reemplazar setx CLAUDE_CODE_OAUTH_TOKEN "PEGA_AQUI_EL_TOKEN"
    Así SÍ — token real adentro setx CLAUDE_CODE_OAUTH_TOKEN "sk-ant-oat01-Ab3xK9...z7Qw"

    Antes de dar Enter, checa estas 4 cosas

    • La palabra PEGA_AQUI_EL_TOKEN ya no aparece en ninguna parte.
    • Hay exactamente dos comillas: una antes del token y una después. Ni más, ni menos.
    • Todo está en un solo renglón.
    • No cambiaste ni una letra del nombre en mayúsculas que va antes de las comillas.

    PowerShell debe responder SUCCESS: Specified value was saved. Si dice otra cosa, casi siempre es una comilla suelta: corrige en el Bloc de notas y vuelve a pegar.

  3. 3

    Cierra PowerShell y ábrelo otra vez Obligatorio

    El token no existe para la terminal hasta que abres una ventana nueva. Ciérrala con la X y vuelve a abrir PowerShell desde cero.

    Este es el paso que la gente se salta, y luego Claude sigue pidiendo iniciar sesión.

  4. 4

    Entra a tu carpeta de trabajo

    Si no tienes un proyecto en mente, tu carpeta de usuario está bien:

    Ir a la carpeta 
    cd $env:USERPROFILE
  5. 5

    Arranca

    Iniciar 
    claude

    Si todo salió bien, entra directo: no pide correo ni contraseña.

Si algo falla

Dice que no reconoce el comando claude

La instalación no terminó, o no se reabrió la terminal. Repite el paso 1, cierra PowerShell y ábrelo de nuevo.

Sigue pidiendo iniciar sesión

El token no se guardó. Comprueba con echo $env:ANTHROPIC_API_KEY (o echo $env:CLAUDE_CODE_OAUTH_TOKEN en la Ruta B). Si sale vacío, repite el paso 2 revisando las comillas.

Error invalid API key o 401

El token está incompleto, vencido o revocado. Que lo revise quien lo generó.

Quiero probar sin dejarlo guardado

Usa $env:ANTHROPIC_API_KEY = "el-token"; claude — vive solo en esa ventana y se borra al cerrarla.

La app de Claude no acepta tokens

Aquí no hay pasos, porque no se puede:

  • La app de escritorio y claude.ai solo entran con correo y contraseña, o con el SSO de la empresa.
  • Claude Code en web también pide iniciar sesión con cuenta.

Si de verdad necesita la app, la única salida es que le den un asiento en el plan de la organización.

Antes de compartir un token

Si el token salió de la suscripción personal de otra persona, compartirlo va contra los términos de uso de Anthropic y pueden suspender la cuenta original.

Si es una API key, todo el consumo se le factura a quien la generó, sin límite por usuario.

Lo sano es pedir un asiento en la organización. Lo demás es decisión de ustedes.
