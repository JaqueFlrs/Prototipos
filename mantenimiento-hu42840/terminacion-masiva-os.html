Pantalla 2A — Filtros (estado inicial)
Estado al abrir la utilería. Listado vacío hasta hacer clic en Generar. Botón Terminar deshabilitado hasta tener ≥1 registro seleccionado.
  • Fecha inicio / Fecha fin: tipo fecha, ambos obligatorios. Si alguno está vacío → mensaje "El rango de fechas es obligatorio".
  • Unidad: campo de texto + botón "..." que abre el Catálogo de Unidades. Opcional — si se deja vacío aplica a todas las unidades.
  • Estatus: combo fijo con valores Abierta / Autorizada / Ambas. Default: Ambas. Opcional.
  • Fecha de cierre: tipo fecha, obligatoria. Default = fecha del día al abrir la utilería. El usuario puede modificarla. Si se borra y se intenta ejecutar → mensaje "La fecha de cierre es obligatoria". Se aplica igual a todos los registros procesados en esa ejecución.
  • Filtro silencioso al generar: excluye OS Terminadas, OS Canceladas, OS con artículos de inventario afectados, OS con devolución registrada. No se muestra mensaje por los excluidos.
